This is a [React Native](https://reactnative.dev) 0.84 app. Use **pnpm** (not npm/npx).

```sh
cd src/Clients/mobile/JJDevHubMobile
pnpm install
pnpm start
```

In another terminal, with an emulator or device attached (`adb devices`):

```sh
pnpm android
```

JDK 17 (`JAVA_HOME=/usr/lib/jvm/java-17-openjdk`). `android/gradlew` is in the repo.
